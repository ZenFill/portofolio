# Portofolio

Personal interactive portfolio website built with **Astro 7**, **Vanilla TypeScript 7 (Strict Mode)**, **Motion.dev**, and **GSAP**.

## ✨ Features

- **Synchronized Preloader Animation**:
  - Dynamic connector line bridging `WELCOME TO` and `MY WEBSITE` (expanding and converging smoothly).
  - Bottom-center percentage counter (`100%` $\rightarrow$ `0%` $\rightarrow$ `100%`) synchronized 1:1 with the connector line.
  - Floating & softly breathing background constellation of 16 developer stack logos.
  - Smooth Top & Bottom Curtain Split transition powered by **Motion.dev**.
- **Coming Soon Screen**:
  - Zero-blink kinetic character roll animation powered by **Motion.dev** (`animate` & `stagger`).
  - Responsive multi-column counter-scrolling **Gallery Grid** background with subtle pointer parallax.
  - Friendly, eye-comfortable Modern Blue UI/UX palette.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server (http://localhost:4321)
npm run dev

# Build for production
npm run build
```
